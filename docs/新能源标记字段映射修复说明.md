# 新能源标记字段映射修复说明

## 问题描述

在合格证查询结果表格中，新能源标记列无法正常显示数据。

## 问题原因

前后端字段名不一致导致数据映射失败：

### 后端返回字段

- 数据库字段：`XNYBJ` (varchar(5) - 字符串类型)
- 后端映射字段：`newEnergyFlag` (字符串类型)
- 定义位置：
  - `backend/app/schemas/certificate.py` - Schema定义
  - `backend/app/routers/certificate_quantity.py` - 字段映射

### 前端期望字段

- 前端映射字段：`newEnergyMark` (错误)
- 定义位置：`frontend/src/components/CertificateResultTable.vue`

### 数据流

```
数据库 XNYBJ (varchar)
  → 后端映射为 newEnergyFlag (string)
  → API返回 { newEnergyFlag: "是" }
  → 前端期望 newEnergyMark (不存在)
  → 显示为空
```

## 修复方案

将前端字段名从 `newEnergyMark` 修改为 `newEnergyFlag`，与后端保持一致。

## 修改内容

### 1. CertificateResultTable.vue

**文件路径**: `frontend/src/components/CertificateResultTable.vue`

**修改位置**: 第335行，字段映射配置

**修改前**:

```typescript
'XNYBJ': {
  key: 'newEnergyMark',  // ❌ 错误
  label: '新能源标记',

```

**修改后**:

```typescript
'XNYBJ': {

  width: 120,
  align: 'center'

```

### 2. api.ts 类型定义

**文件路径**: `frontend/src/types/api.ts`

**修改位置**: CertificateQuantityItem 接口

**修改前**:

```typescript
export interface CertificateQuantityItem {
  // ... 其他字段
  fuelType?: string;
  newEnergyType?: string; // 只有类型，没有标记
```

**修改后**:

```typescript
  // ... 其他字段
  fuelType?: string;
  newEnergyFlag?: string; // 新能源标记 ✅ 新增
  newEnergyType?: string; // 新能源类别
  productionAddress?: string;
  // ...
}
```

## 数据类型说明

### 字段类型

- **数据库**: `XNYBJ varchar(5)` - 字符串类型
- **后端**: `newEnergyFlag: Optional[str]` - 字符串类型
- **前端**: `newEnergyFlag?: string` - 字符串类型

### 可能的值

根据数据库定义，该字段存储的是字符串值，可能的值包括：

- `"是"` - 是新能源车辆
- `"否"` - 不是新能源车辆
- `null` 或空字符串 - 未标记
